\chapter*{Glossaire}
\begin{description}
    \item[API] : (Application Programming Interface) est un programme permettant \`a deux applications distinctes de communiquer et d'\'echanger des donn\'ees.
    \item[Conteneur] : environnement d'ex\'ecution \`a une image Docker.
    \item[Docker] : est un logiciel de virtualisation, plus pr\'ecis\'ement un isolateur permettant de lancer des conteneurs encapsulant des logiciels.
    \item[Dockerfile] : fichier texte contenant des commandes permettant la compilation d'une image Docker.
    \item[DPE] : (Diagnostic de performance \'energ\'etique) donne des informations sur la performance \'energ\'etique et climatique d'un logement ou d'un b\^atiment.
    \item[Endpoint] : est l'extr\'emit\'e d'un canal de communication, point par lequel une API entre en contact avec d'autres syst\`emes.
    \item[ExpressJS] : est un framework pour construire des applications web bas\'e sur NodeJS.
    \item[HTTPS] : (Hypertext Transfer Protocol Secure) est un protocole s\'ecuris\'e d'\'echange de
donn\'ees entre un navigateur web et un site web.
    \item[Image Docker] : r\'esultat que l'on obtient apr\`es la compilation d'un Dockerfile, repr\'esentant notre logiciel.
    \item[Kubernetes] : est un syst\`eme open-source permettant d'automatiser le d\'eploiement, la
gestion de conteneurs d'applications et de clusters.
    \item[NodeJS] : environnement d'ex\'ecution de programme JavaScript en dehors du navigateur
gr\^ace \`a l'encapsulation du moteur V8 de Google Chrome.
    \item[PostgreSQL] : est un syst\`eme de gestion de base de donn\'ees relationnelle et objet.
    \item[SSH] : (Secure Shell) est un protocole s\'ecuris\'e qui impose un \'echange de cl\'es de chiffrement en d\'ebut de connexion entre plusieurs ordinateurs via l'\'echange de paquets authentifi\'es.
    \item[WireGuard] : est un protocole de communication et un logiciel libre et open source permettant de cr\'eer un r\'eseau virtuel.
    \item[YAML] : (Yet Another Markup Language) est un format de repr\'esentation de donn\'ees par
s\'erialisation Unicode.
\end{description}
